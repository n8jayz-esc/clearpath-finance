# Deploy ClearPath Finance to GitHub Pages

Upload every file in this folder to the root of your `clearpath-finance` repository.

Then:
Settings → Pages → Build and deployment → Source: Deploy from a branch
Branch: main
Folder: / (root)
Save

Expected live URL:
https://n8jayz-esc.github.io/clearpath-finance/

On iPhone Safari:
Share → Add to Home Screen → Add
